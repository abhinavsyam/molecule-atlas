MOLECULE ATLAS — PRESENTATION COPY

FILES
- app.py: Main Streamlit application
- requirements.txt: Required Python packages
- Start_Molecule_Atlas.bat: Double-click this file to start the app on Windows

FIRST-TIME SETUP (only if packages are not installed yet)
1. Open this folder in File Explorer.
2. Click the address bar, type cmd, and press Enter.
3. Run: py -m pip install -r requirements.txt

TO START THE APP
Double-click Start_Molecule_Atlas.bat.
Wait for the terminal to show a Local URL, usually http://localhost:8501.
If the browser does not open automatically, enter http://localhost:8501 in your browser.
Keep the terminal window open while presenting. Closing it stops the app.

MOLECULES
Acetic acid, methyl alcohol (methanol), nitrobenzene, camphor, propene, and hydrogen cyanide (HCN).
